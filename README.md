# iui-pregnancy-prediction
Machine learning model for predicting IUI clinical pregnancy outcomes with temporal validation and Streamlit clinical decision support tool

## Naming note
> `src/first_visit_model.ipynb` and its saved artifacts
> (`models/saved_models/first_visit_model/`) correspond to the
> **"Pre-treatment Model"** described in the manuscript and shown in the
> deployed Streamlit app. The code retains its original internal name
> ("First-Visit") for historical development reasons; the two names
> refer to the exact same model.
>
> Similarly, `src/model_training.ipynb` corresponds to the
> **"Procedure-Day Model"**.
